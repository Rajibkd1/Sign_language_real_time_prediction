## Project and role

BdSL Vision is a public research prototype for continuous Bangla Sign Language
sentence recognition using camera or uploaded video, with a React frontend,
FastAPI, MediaPipe and a PyTorch CTC model. Rajib Kumar Dhar (@Rajibkd1) owns
the repository and is identified as the author of the supplied final-year
report. Repository ownership is visible publicly; any required write-access
verification should use the applicant's own account.

## Ecosystem relevance

The project's intended contribution is an inspectable camera-to-Bangla-text
workflow for developers exploring BdSL accessibility tools. Continuous sentence
input, landmark-based modeling and documented inference diagnostics can help
others investigate this task. This is a statement of intended usefulness;
external deployments, community adoption and measurable user impact have not
been established here.
